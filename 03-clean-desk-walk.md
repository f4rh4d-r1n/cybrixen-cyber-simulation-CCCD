# 🧹 Mission 3: Clean-desk walk

> **Score: 5.8 / 10** 🟡 · 📍 Whole floor · 🛠️ Click objects around the office · 🏷️ Physical security, Security awareness

## 🎯 The mission
Walk the office like an end-of-day security officer. Find the physical security problems people left behind and fix each one the **safest sensible** way. Harmless things had to be left alone.

## 🔎 What counts as a problem
| Problem | Right action |
|---------|--------------|
| 📝 Secrets on paper (passwords, PINs, codes) | Remove or destroy it **and report to IT** so the secret gets changed |
| 💻 Unlocked computer showing sensitive data | **Lock the screen** (signing out loses unsaved work) |
| 🔌 Unknown USB stick | **Never plug it in.** Bag it and hand it to IT security |
| 🚪 Secure door propped open | Remove what's holding it and close it |
| 📄 Confidential papers left out | Put them in the confidential shred bin |

## ✅ What I got right
- Closed the SOC door so only badge holders can enter
- Handed an unknown USB stick to IT security without plugging it in
- Removed notes showing a banking token PIN and a router admin password, and reported both
- Locked an unattended workstation showing confidential HR records

## ❌ Where I lost marks
| Mistake | Lesson |
|---------|--------|
| Shredded three **harmless reminder notes** (like "buy milk") | Not everything on a desk is a problem. Acting on harmless items costs points |
| Left a sheet of **network passwords face-up** | Still exposed to anyone walking past |

## 📚 Lessons
- 🧐 **Inspect before you act.** The brief said so and I still over-corrected.
- Over-reaction is a real security cost too: shredding someone's note disrupts normal work.
- When a secret has been exposed, removing it is not enough. It needs to be **rotated**.
